## 2. 데이터 전처리 계획

1. **헤더 정리**: 원본 xlsx 상단 메타 행(출처, 조회기간 등) 제거 후 실제 헤더 행 지정
2. **계층 구조 평탄화**: 중분류 합계(소계) 행 분리 → 소분류 단위 데이터만 분석에 사용
3. **기간 파싱**: "2021년 01월" 형식 → `datetime` 변환 후 연도·월 컬럼 분리
4. **결측치 처리**: 구인/구직/취업인원 0 또는 NaN → 해당 월 데이터 없음으로 처리
5. **파생 변수 생성**
   - `취업연결비율(%)` = 취업건수 / 구직건수 × 100 (구직건수는 신청 건수 기준으로 엄밀한 취업률과 다름)
   - `경쟁률` = 구직건수 / 구인인원 (값 클수록 취업 경쟁 치열)
   - `구인 성장률` = 전년 동월 대비 구인인원 증감률

## 5. 자동화 서비스 (Streamlit + LLM)

**입력**
- 사용자가 자신의 전공, 관심사, 강점 등을 **자유 서술형 텍스트**로 직접 입력
  - 예: "저는 컴퓨터공학을 전공했고 데이터 분석과 파이썬에 관심이 많습니다. 사람들과 소통하는 일도 좋아해요."

**처리 (1단계 — LLM 의도 분석)**
- 사용자 입력 텍스트를 LLM에 전달
- LLM이 입력 내용을 분석하여 관련성 높은 직종 중분류를 데이터 내 항목 기준으로 매핑

**처리 (2단계 — 데이터 조회)**
- LLM이 선별한 중분류에 해당하는 직종의 최근 구인인원, 경쟁률, 성장률, 취업연결비율을 데이터에서 추출

**처리 (3단계 — LLM 최종 추천)**
- 추출된 수치 데이터를 다시 LLM에 전달
- LLM이 수치를 종합 분석하여 **구체적인 직업명** 수준으로 추천 및 이유 서술
  - 예: "데이터 분석가", "백엔드 개발자", "IT 컨설턴트" 등 실제 직업 단위까지 좁혀 추천

**출력**
- **LLM 추천 리포트**: 구체적 직업명 + 추천 이유 + 해당 직종의 현재 시장 현황(경쟁률·성장률 해석) + 취업 준비 방향 자연어 서술
- 관련 직종 중분류의 월별 구인 추이 차트
- 직종별 경쟁률 비교 차트
