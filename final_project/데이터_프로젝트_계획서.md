## 2. 풀고 싶은 문제

**_데이터로 K-pop의 글로벌 경쟁력을 분석하고 싶다_**

> 핵심 연구 질문: **"K-pop의 오디오 특성은 글로벌 인기 장르와 얼마나 닮았는가?"**

Spotify `popularity` 점수를 글로벌 성공 가능성의 대리 지표(proxy)로 활용하여, K-pop 트랙의 오디오 특성 프로파일이 인기 장르들과 어떻게 다르고 얼마나 유사한지 탐색적으로 분석한다.

**예측/분류 대상:**
- K-pop vs. 글로벌 인기 장르(Pop, Hip-hop, Latin, R&B 등)의 오디오 특성 비교
- 고인기 트랙(popularity 상위 20%) 프로파일과 K-pop의 적합도 수치화
- 오디오 특성(danceability, energy 등)과 popularity 간 상관관계

## 3. 만들 서비스 (완성 모습)

### 3-1. EDA 분석 대시보드
**사용자 입력 →** 2022년 Spotify 트랙 데이터 (장르, 오디오 특성값)
**화면 출력 →** 장르별 오디오 특성 평균 비교 (레이더 차트), 고인기 트랙 프로파일 추출 (히트맵), 특성-인기도 상관관계 분석 등

### 3-2. 최신 K-pop 글로벌 인기도 예측 파이프라인 (ML + API)
**사용자 입력 (Input) →** 웹 대시보드(Streamlit) 검색창에 분석할 최신 K-pop 트랙의 Spotify 주소(URI) 입력

**백엔드 처리 과정 (Processing) →**
1. **API 호출:** 파이썬 `spotipy` 라이브러리를 통해 백엔드에서 Spotify Web API와 통신하여, 입력된 최신 곡의 14가지 오디오 특성값을 실시간으로 추출.
2. **데이터 전처리:** 추출된 데이터를 머신러닝 모델의 입력 형태(DataFrame)로 변환.
3. **모델 예측:** 2022년 데이터로 사전 학습 및 저장된 머신러닝 모델에 최신 데이터를 입력하여 `popularity` 점수 계산.

**화면 출력 (Output) →**
- **예측 점수:** 0~100점 척도의 예상 스포티파이 인기도
- **결과 해석:** "2022년 글로벌 메가 히트곡 트렌드 기준, 이 곡은 상위 O% 수준의 오디오 특성을 가졌습니다."
- **시각화:** 기존 K-pop 평균 오디오 특성과 검색한 최신 곡의 특성을 비교하는 방사형 차트 제공.

**기술 스택:** Python 3, pandas, scikit-learn (ML), **spotipy (Spotify Web API)**, **Streamlit (웹 프론트엔드 대시보드 구축)**, plotly

## 4. 예상 난관 및 해결 방안

> **과거 데이터(2022)와 최신 트렌드 간의 차이 (Data Drift) 및 API 호출 제한**

1. **트렌드 변화 한계:** 모델은 2022년의 인기 패턴을 학습했기 때문에, 최신 곡을 이 모델에 넣었을 때 나오는 예측 점수는 "현재 시점의 실제 순위"라기보다는 "2022년 글로벌 기준의 성공 확률"에 가깝다. 음악 트렌드가 변했을 가능성이 있으므로 결론 도출 시 이 한계점을 명확히 짚어야 한다.
2. **API Rate Limit (호출 제한):** Spotify API는 과도한 트래픽을 막기 위해 호출 횟수 제한이 있다. 파이썬 코드 레벨에서 예외 처리(try-except)를 구성하고, 한 번 조회한 곡의 특성 데이터는 캐싱(Caching) 처리하여 불필요한 API 중복 호출을 방지하는 로직을 추가해야 한다.
