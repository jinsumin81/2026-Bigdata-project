## 1. 문제 정의

K-pop은 최근 10년간 전 세계적으로 폭발적인 인기를 얻고 있지만, 그 성공이 **음악 자체의 오디오 특성**에 기인하는지, 아니면 외부적 요인(마케팅, SNS 등)에 의한 것인지는 데이터로 검증된 바가 많지 않다. 본 프로젝트는 Spotify가 제공하는 오디오 특성(danceability, energy, valence 등)을 활용해 **K-pop의 글로벌 경쟁력을 수치로 분석**하고, 나아가 오디오 특성만으로 인기도(popularity)를 예측하는 머신러닝 서비스를 구현한다.

**핵심 연구 질문:**
> "K-pop의 오디오 특성은 글로벌 인기 장르와 얼마나 닮았는가? 그 유사성이 글로벌 성공에 영향을 미치는가?"

| # | 세부 연구 질문 | 분석석 방법 |
|---|--------------|-----------|
| RQ1 | K-pop 평균 오디오 특성은 글로벌 인기 장르와 어떤 차이가 있는가? | 장르별 평균 비교, 레이더 차트 |
| RQ2 | 고인기 트랙(상위 20%)의 공통 오디오 특성 패턴은? | 히트맵, 분위수 그룹화 |
| RQ3 | 어떤 오디오 특성이 popularity와 가장 강한 상관관계를 갖는가? | 피어슨 상관계수, 산점도 |
| RQ4 | 오디오 특성만으로 popularity를 예측하는 모델은 얼마나 정확한가? | Linear Regression, Random Forest |

**예측 대상 (target):** `popularity` — Spotify가 부여하는 0~100점의 인기도 점수 (연속형 회귀 문제)

## 2. 데이터 소개 & EDA

### 데이터 규모

| 항목 | 내용 |
|------|------|
| 출처 | Spotify Web API (2022년 수집) |
| 크기 | 114,000개 트랙 · 114개 장르 · 20개 컬럼 |
| 형식 | CSV (tabular) |
| K-pop 트랙 수 | 약 1,000개 (전체의 약 1%) |

### 주요 컬럼

| 컬럼명 | 설명 |
|--------|------|
| `popularity` | 인기도 점수 0~100 (타깃 변수) |
| `danceability` | 춤추기 적합한 정도 (리듬·템포 기반) |
| `energy` | 음악적 강렬함·활동성 |
| `valence` | 긍정적 감정의 정도 |
| `acousticness` | 어쿠스틱 악기 사용 비율 |
| `instrumentalness` | 보컬 없는 연주 비율 |
| `loudness` | 전체 음량 (dB) |
| `tempo` | 박자 속도 (BPM) |
| `track_genre` | 장르 레이블 (114개 카테고리) |

### EDA 주요 발견

1. **K-pop의 오디오 특성 프로파일**: K-pop은 비교 대상 장르(pop, hip-hop, latin, r-n-b, dance) 대비 `danceability`와 `energy`가 높고, `acousticness`가 현저히 낮아 전자음악 중심의 구성임을 확인
2. **Popularity = 0 문제**: 전체 트랙의 상당 비율이 popularity = 0으로, 사실상 미노출 트랙임. 모델 학습 전 `popularity > 0` 필터링 적용
3. **샘플 불균형**: K-pop이 전체의 약 1%에 불과해 통계적 불확실성이 존재. 비교 장르를 동일 샘플 수(약 1,000개)로 맞춰 공정한 비교 수행

### 결측·이상치 처리

- 결측치: 데이터셋 내 결측 없음 확인 (`isna().sum()` = 0)
- 중복 제거: `track_id` 기준 `drop_duplicates()` 적용
- `duration_ms` → 분(min) 단위로 파생 변수 생성
- `popularity = 0` 트랙 학습 데이터에서 제외

## 3. 특성 엔지니어링

### 사용한 피처 (12개)

```
danceability, energy, valence, acousticness, instrumentalness,
liveness, speechiness, loudness, tempo, duration_ms, key, mode
```

장르 레이블(`track_genre`)은 **의도적으로 제외**. 오디오 특성만으로 인기도를 예측하는 것이 본 프로젝트의 핵심 목적이기 때문.

### 파생 변수

| 파생 변수 | 생성 방법 | 근거 |
|-----------|-----------|------|
| `duration_min` | `duration_ms / 60000` | 밀리초보다 직관적인 단위로 EDA 활용 |
| `popularity_group` | popularity 상위 20% → "high", 나머지 → "low" | 고인기 트랙 패턴 분析에 활용 |

### 전처리

- `StandardScaler`로 전체 피처 정규화 (loudness: -60~0 dB, tempo: 50~220 BPM 등 스케일 차이가 크므로 필수)

## 4. 모델 / 서비스

### 사용한 방법: 머신러닝 (표 데이터 회귀)

오디오 특성 12개 → popularity 예측 (연속형 회귀 문제)

| 모델 | 선택 이유 |
|------|-----------|
| Linear Regression | 베이스라인. 최소 기준선 제시 |
| Random Forest Regressor | 비선형 관계 포착, Feature Importance 해석 가능 |

### 입력 → 출력 흐름

```
[사용자: 슬라이더로 오디오 특성 12개 입력]
        ↓
[StandardScaler로 정규화]
        ↓
[Random Forest 모델 → predict()]
        ↓
[예측 점수 출력 (0~100)]
        ↓
[레이더 차트: 입력 곡 vs K-pop 평균 vs 글로벌 상위 20% 비교]
```

### 성능 지표

| 모델 | RMSE | MAE | R² |
|------|------|-----|----|
| Linear Regression (베이스라인) | — | — | — |
| Random Forest | — | — | — |

> ※ 실행 후 실제 수치로 채울 것. 목표: RMSE 15 이하, R² 0.2 이상

**성능 해석:** 음악 인기도는 마케팅·아티스트 인지도·발매 시기 등 오디오 특성 외 요인에 크게 좌우되므로 R²가 낮게 나오는 것은 예상된 결과. "완벽한 예측"보다 **Feature Importance를 통한 트렌드 파악**에 집중한다.

## 6. 결론 & 한계

### 알게 된 것

- K-pop은 글로벌 주요 장르 대비 **danceability·energy가 높고 acousticness가 낮은** 일관된 오디오 프로파일을 가짐
- 고인기 트랙(상위 20%)에서는 **loudness·energy**가 popularity와 양의 상관관계를 보임
- 오디오 특성만으로도 인기도의 대략적인 **방향성(트렌드)** 은 예측 가능하나, 정확한 수치 예측에는 한계가 있음
- Feature Importance 분석 결과, **loudness·tempo·duration_ms** 등이 popularity 예측에 가장 큰 영향을 미침

### 한계 (Limitations)

| 한계 | 내용 |
|------|------|
| Data Drift | 모델은 2022년 데이터 기반 → 2024~2025년 최신 트렌드와 차이 가능성 존재 |
| 외부 변수 미포함 | 마케팅 예산, 아티스트 팔로워 수, 발매 시기 등이 popularity에 더 큰 영향을 미칠 수 있음 |
| K-pop 샘플 편중 | 전체의 약 1%로 통계적 불확실성 존재 |
| Popularity 지표 한계 | Spotify popularity는 최근 재생 횟수에 가중치를 두므로 "음악 자체의 품질"과 다를 수 있음 |

### 향후 과제

- 최신 Billboard/Melon 차트 데이터 추가 수집 → 2022년 vs. 최신 트렌드 비교
- XGBoost 모델 추가 비교 및 하이퍼파라미터 튜닝 (RandomizedSearchCV)
- Spotify API(spotipy) 연동 → Spotify URL 입력 시 실시간 오디오 특성 추출 후 예측
