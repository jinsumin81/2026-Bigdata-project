## 2. 풀고 싶은 문제

**_데이터로 K-pop의 글로벌 경쟁력을 분석하고 싶다_**

### 핵심 연구 질문

> **"K-pop의 오디오 특성은 글로벌 인기 장르와 얼마나 닮았는가? 그 유사성이 글로벌 성공에 영향을 미치는가?"**

Spotify `popularity` 점수를 글로벌 성공 가능성의 대리 지표(proxy)로 활용하여, K-pop 트랙의 오디오 특성 프로파일이 인기 장르들과 어떻게 다르고 얼마나 유사한지 탐색적으로 분석한다.

### 세부 연구 질문 (Research Questions)

| # | 질문 | 분석 방법 |
|---|------|-----------|
| RQ1 | K-pop의 평균 오디오 특성은 글로벌 인기 장르(Pop, Hip-hop 등)와 어떤 차이가 있는가? | 장르별 평균 비교, 레이더 차트 |
| RQ2 | popularity 상위 20% 고인기 트랙들의 공통 오디오 특성 패턴은 무엇인가? | 분위수 그룹화, 히트맵 |
| RQ3 | 어떤 오디오 특성이 popularity와 가장 강한 상관관계를 갖는가? | 피어슨 상관계수, 산점도 |
| RQ4 | 오디오 특성만으로 popularity를 예측하는 머신러닝 모델은 얼마나 정확한가? | Random Forest / XGBoost 회귀 |
| RQ5 | 2024~2025년 최신 K-pop 히트곡은 2022년 글로벌 인기 패턴에 얼마나 부합하는가? | Spotify API 실시간 특성 추출 후 모델 예측 |

## 3. 만들 서비스 (완성 모습)

### 3-1. EDA 분석 대시보드

**목적:** 2022년 Spotify 데이터를 기반으로 K-pop과 글로벌 인기 장르 간 오디오 특성 차이를 시각적으로 비교

**입력:** 2022년 Spotify 트랙 데이터 (CSV)

**출력 및 시각화 목록:**

| 시각화 | 사용 라이브러리 | 목적 |
|--------|----------------|------|
| 레이더 차트 (방사형) | plotly | 장르별 평균 오디오 특성 6~8개 동시 비교 |
| 히트맵 | seaborn | 고인기 트랙의 오디오 특성 간 상관관계 |
| 박스플롯 | plotly | 장르별 popularity 분포 비교 |
| 산점도 (회귀선 포함) | plotly | 주요 특성(danceability, energy 등) vs. popularity |
| 바이올린 플롯 | seaborn | K-pop vs. Pop: danceability, energy 분포 비교 |
| 막대 차트 | plotly | 장르별 평균 popularity 순위 |

**전처리 단계 (EDA 전 필수):**
1. 결측치 확인 및 제거 (`isnull().sum()` 기준 5% 이상 컬럼 제거 또는 평균 대체)
2. 중복 트랙 제거 (`track_id` 기준 drop_duplicates)
3. `popularity = 0`인 데이터 비율 확인 → 분석 제외 여부 결정
4. `duration_ms` → 분(min) 단위 변환
5. 분석 대상 장르 필터링: K-pop + 비교 장르 5개 선별

### 3-2. 최신 K-pop 글로벌 인기도 예측 파이프라인 (ML + API)

**목적:** 사용자가 최신 K-pop 곡의 Spotify 링크를 입력하면, 해당 곡의 오디오 특성을 실시간으로 가져와 사전 학습된 모델로 예상 인기도를 예측

#### 입력 (Input)
- 사용자가 Streamlit UI에 Spotify 트랙 URL 또는 URI 입력
  - 예시: `https://open.spotify.com/track/4cluDES4hQEUhmXj6TXkSo`

#### 처리 과정 (Pipeline)

```
[사용자 입력: Spotify URL]
        ↓
[URL 파싱 → Track ID 추출]
        ↓
[spotipy API 호출 → audio_features() 14개 특성값 수집]
        ↓
[캐시 확인: 이미 조회된 Track ID면 DB에서 바로 반환]
        ↓
[전처리: 학습 데이터와 동일한 피처 스케일링 적용 (StandardScaler)]
        ↓
[저장된 ML 모델(.pkl) 로드 → predict()]
        ↓
[결과 출력: 예측 점수 + 방사형 차트 + 해석 텍스트]
```

#### ML 모델 학습 계획

| 항목 | 내용 |
|------|------|
| **타깃 변수** | `popularity` (연속형 회귀 문제) |
| **피처** | danceability, energy, valence, acousticness, instrumentalness, liveness, speechiness, loudness, tempo, duration_ms, key, mode (12개) |
| **학습 데이터** | 전체 114,000개 중 K-pop 외 장르 포함 전체 사용 (장르 레이블 제외) |
| **검증 방식** | 80:20 Train-Test Split + 5-Fold Cross Validation |
| **평가 지표** | RMSE (주), MAE, R² Score |
| **비교 모델** | Linear Regression (베이스라인), Random Forest Regressor, XGBoost Regressor |
| **하이퍼파라미터 튜닝** | RandomizedSearchCV (n_estimators, max_depth, learning_rate 등) |
| **모델 저장** | `joblib.dump()` → `.pkl` 파일로 저장 후 Streamlit에서 로드 |

#### 출력 (Output)

- **예측 점수:** "예상 인기도: **72 / 100**"
- **결과 해석:** "2022년 글로벌 기준, 이 곡은 상위 **18%** 수준의 오디오 특성을 가지고 있습니다."
- **비교 시각화:** 아래 3가지 요소를 하나의 화면에 표시
  1. 입력 곡의 오디오 특성 레이더 차트
  2. K-pop 장르 평균 특성 레이더 차트 (겹쳐서 비교)
  3. 글로벌 인기 상위 20% 트랙 평균 특성 레이더 차트

## 4. 예상 난관 및 해결 방안

### 난관 1: 과거 데이터(2022)와 최신 트렌드 간의 차이 (Data Drift)

- **문제:** 모델은 2022년의 인기 패턴을 학습했기 때문에, 2024~2025년 최신 곡을 이 모델로 예측하면 실제 현재 순위와 오차가 발생할 수 있음.
- **해결:**
  - 예측 결과 해석에 "2022년 글로벌 기준의 성공 확률" 임을 명시하는 문구를 UI에 고정 표시
  - 결론 보고서에 Data Drift 한계를 분석의 Limitation 섹션으로 별도 작성
  - 가능하면 최신 Billboard/Melon 차트 데이터를 추가 수집해 2022년 vs. 최신 트렌드 비교 분석 추가 (확장 과제)

### 난관 2: Spotify API Rate Limit (호출 제한)

- **문제:** Spotify Web API는 단기간 과도한 요청 시 `429 Too Many Requests` 오류 발생
- **해결:**
  - `@st.cache_data(ttl=3600)` 데코레이터를 통해 같은 Track ID에 대한 결과를 1시간 동안 캐싱
  - API 호출 실패 시 `try-except` 블록으로 사용자 친화적 오류 메시지 출력
  - 스크립트 실행 단계에서 `time.sleep(0.5)` 간격으로 API 안정적 호출

### 난관 3: K-pop 데이터 샘플 불균형 (약 1,000개 vs. 전체 114,000개)

- **문제:** K-pop 샘플(약 1%) 비율이 낮아 EDA에서 K-pop 통계가 다른 장르보다 불안정할 수 있음
- **해결:**
  - K-pop EDA 시 신뢰구간(95% CI) 또는 표준편차를 함께 표시하여 불확실성 명시
  - 비교 대상 장르도 동일 샘플 수(약 1,000개)로 랜덤 샘플링하여 공정한 비교 수행

### 난관 4: popularity 예측의 낮은 R² 문제

- **문제:** 음악 인기도는 오디오 특성 외에 마케팅, 아티스트 유명도, 발매 시기 등 외부 요인에 크게 좌우되므로 R²가 낮게 나올 가능성이 높음
- **해결:**
  - R²보다 RMSE/MAE 중심으로 평가, "완벽한 예측"보다 "트렌드 파악"에 목적을 맞춤
  - 보고서에 모델의 한계(외부 변수 미포함)를 명확히 서술
  - Feature Importance 분석으로 어떤 특성이 인기도에 영향을 미치는지 해석 가능성(Interpretability)에 집중

## 6. 기대 결과 및 결론 방향

- **EDA 결과 예상:** K-pop은 Pop보다 `danceability`와 `energy`가 높고, 서양 팝보다 `acousticness`가 낮아 전자음악 중심 구성임을 확인할 것으로 예상
- **모델 성능 목표:** RMSE 15 이하, R² 0.2 이상 (popularity 예측의 근본적 한계를 고려)
- **서비스 시연:** 아이브 "Accendio", 르세라핌 "HOT" 등 2024~2025년 최신 K-pop 히트곡을 입력하여 예측 점수 및 비교 차트 실시간 시연
